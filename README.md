# Enunciado do Desafio: MIPS Memory Forensics

## Alerta de Segurança e Contexto

Um incidente cibernético corrompeu os módulos de controle primários de um sistema embarcado de missão crítica. Para salvar as credenciais do sistema, a chave de foi segmentada em dois blocos de 4 bytes e injetada no espaço de memória RAM.

---

## 📋 Especificações da Memória

- **Arquitetura Base:** Subconjunto MIPS de 32 bits.
- **Tamanho de cada endereço:** 4 bytes.
