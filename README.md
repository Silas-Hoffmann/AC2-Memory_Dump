# Enunciado do Desafio: MIPS Memory Forensics

## Alerta de Segurança e Contexto

Um incidente cibernético corrompeu os módulos de controle primários de um sistema embarcado de missão crítica. Para salvar as credenciais do sistema, a chave de segurança foi segmentada, criptografada e injetada no espaço de memória RAM. Encontre a chave de segurança e recupere a flag para reiniciar os módulos de controle.

---

## Especificações da Memória

- **Arquitetura Base:** Subconjunto MIPS de 32 bits.
- **Tamanho de cada endereço:** 4 bytes.
- **Memory Range:** 50 espaços
